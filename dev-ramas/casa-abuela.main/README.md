# casa-abuela
Casa Abuela · calendario familiar (Utilo, T0471)

- `index.html`: la web (GitHub Pages). Llega a la web al fusionar en `main`.
- `apps-script/`: el código del proyecto de Apps Script «Casa Abuela» (desde T0479), que guarda en el Sheet. Fusionar no lo despliega: se sube con `clasp push` y se actualiza la implementación de la API con `clasp deploy -i <id de la URL de CASA_API>`, siempre antes de fusionar la web que lo necesita. Al desplegarlo, un tag en ese commit con la versión de la implementación (`git tag apps-script-v34 && git push origin apps-script-v34`): así su tarea del DAILY sabe que ya está en uso.
- `utilo.json`: cómo se publica cada cosa, para que las tareas pasen solas a Entregada (T0611; en utilo-apps, `docs/PROYECTO_SUELTO.md`). Prueba: `node apps-script/probar.js apps-script/Código.js`.
- `firebase-messaging-sw.js`: recibe los avisos al móvil aunque la app esté cerrada (T0623). Los manda el Apps Script (`revisarAvisos`, cada 5 minutos) por Firebase Cloud Messaging cuando cambia quién viene hoy o mañana; de momento, solo a la abuela (el botón «Activar avisos» de su vista). La configuración web de Firebase y su clave pública van en `window.CASA_FIREBASE` de `index.html`; la cuenta de servicio (el JSON entero), en la propiedad del script `FCM_CUENTA`, nunca en el repositorio. Horas sin avisos: `AVISOS_CALLA` y `AVISOS_HABLA` en MESA_CONFIG (por defecto, de 22 a 8). La primera vez, desde el editor, **antes** de `clasp deploy`: ejecutar `instalarAvisos` (da los permisos nuevos y crea el disparador). Si se despliega antes, la web deja de funcionar hasta que se den los permisos.
- `dev/`: Casa Abuela en la app «Utilo DEV» con **datos inventados** (T0655), nunca con el Sheet de la familia. `servidor.js` ejecuta el `apps-script/Código.js` de la rama en el navegador sobre un Sheet inventado (`google-falso.js`, el mismo Google falso que usa `apps-script/probar.js`), y la web lo usa por `window.MESA_PREVIEW`. Lo cambiado se queda en ese dispositivo; `#datos-nuevos` vuelve a empezar, `#carmen`, `#abuela`… eligen quién eres. Prueba: `node dev/probar-servidor.js`. Lo sube la acción `.github/workflows/utilo-dev.yml` en cada push (necesita el secreto `UTILO_DEV_TOKEN`); qué página y qué personas, en `utilo.json` · `dev` (en utilo-apps, `docs/PROYECTO_SUELTO.md`, «En la app DEV»). No se publica: la web de verdad no lo carga.
